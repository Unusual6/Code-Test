## 项目经验

### Agent 任务自动化执行平台
**AI 智能体产品经理**  
2025-07 ~ 2026-10

**【原内容】**  
面向 AI4S 领域复杂任务自动化平台，通过 Agent 整合任务理解、知识检索、工作流编排、外部工具调用与智能优化能力，实现从任务需求到自动化执行及结果交付的端到端闭环。

项目背景：针对复杂任务执行过程中流程配置繁琐、跨系统操作成本高、执行过程不透明及参数优化依赖人工经验等问题，建设基于 LangGraph 的 Agent 平台，用户通过自然语言描述任务目标，由 Agent 组织任务执行，并结合知识检索、外部工具调用及贝叶斯优化能力，提升任务执行效率与实验优化效果。

核心工作：  
• 需求分析与产品设计：梳理任务输入、流程执行、人工干预与结果交付的完整链路，设计自然语言与已有流程方案双路径处理机制，明确 Agent 的功能边界及关键人工确认节点。  
• Agent 编排与工具集成：基于 LangGraph 设计任务处理与工作流编排机制，结合 RAG 知识检索，并通过 MCP Server、API/Python 函数及 MQTT 设备网关等方式对接外部系统与设备。  
• 执行控制与结果反馈：设计流程确认、关键参数校验及执行中断机制，打通 Agent、系统网关与外部设备之间的任务调用和状态回传链路，将执行进度、状态及最终结果整合至对话界面。  
• 智能优化与效率提升：研发基于贝叶斯优化 (BO) 的工艺参数寻优算法，通过实验数据迭代寻找更优参数组合，并将优化能力应用于 Agent 任务执行流程。

项目成果：  
• 平台落地：接入 20 台设备，支持 50 种标准化工作流，落地 3 家机构。  
• 用户与使用规模：服务 90 余名实际使用者，月均执行任务 2,000 余项。  
• 任务执行效果：任务成功率约 95%。  
• 算法优化效果：实验验证中，优化轮次由 20 轮降至 10 轮，产率较 20 轮经验调参方案提升超过 5%。
