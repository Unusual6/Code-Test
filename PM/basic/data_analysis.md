# 产品经理数据分析能力清单 + 学习资源

> 目标：帮助产品经理建立完整的数据分析能力体系，从“会看数据”升级到“用数据做决策”。

---

## 一、能力清单总览（按优先级）

### P0：必须掌握（不会就很难做好产品决策）

| 能力模块 | 具体技能 | 掌握标准 |
|---------|----------|----------|
| **指标体系建设** | 北极星指标定义、过程指标与结果指标拆解、虚荣指标识别 | 能独立为产品定义完整指标树，并说明每个指标的业务含义 |
| **漏斗分析** | 转化漏斗拆解、流失点定位、分步骤对比 | 能独立画出完整用户路径漏斗，并定位最大问题环节 |
| **留存分析** | 次日/7日/30日留存、留存曲线、分群留存 | 能解读留存曲线含义，并给出提升假设 |
| **转化率分析** | 注册、激活、付费、复购等关键转化 | 能计算并对比不同渠道/版本的转化差异 |
| **用户分群** | 行为分群、价值分群、生命周期分群 | 能根据业务目标对用户进行有效分群分析 |
| **基础数据解读** | DAU/MAU、PV/UV、跳出率、人均使用时长等 | 能快速判断数据是好是坏，并说出可能原因 |
| **Excel / 表格能力** | 透视表、VLOOKUP/XLOOKUP、基础公式、数据清洗 | 能独立完成日常数据整理与简单分析 |

### P1：强烈建议掌握（拉开差距的关键能力）

| 能力模块 | 具体技能 | 掌握标准 |
|---------|----------|----------|
| **A/B 测试** | 实验设计、样本量估算、显著性判断、常见坑规避 | 能独立设计并解读一次完整的 A/B 实验 |
| **同期群分析（Cohort）** | 按注册时间、渠道等分组看长期变化 | 能用 Cohort 发现整体数据掩盖的问题 |
| **归因分析** | 渠道归因、功能归因、首次/末次触点 | 能判断用户增长真正来自哪里 |
| **用户价值分析** | RFM 模型、LTV 计算、高价值用户识别 | 能区分不同价值用户并制定差异化策略 |
| **异常排查** | 数据波动归因、技术 vs 产品 vs 外部因素判断 | 数据突然变化时，能在 1-2 天内定位原因 |
| **基础 SQL** | SELECT、WHERE、GROUP BY、JOIN、日期函数、窗口函数入门 | 能自己取日常所需数据，减少对数据同学的依赖 |
| **数据可视化** | 选择正确图表、讲清楚数据故事 | 能用图表清晰支撑自己的产品观点 |

### P2：加分项（有余力再学）

- Python（pandas + matplotlib/seaborn）做更灵活的分析
- 统计基础（假设检验、置信区间、相关性 vs 因果）
- 增长模型（AARRR 深度应用、病毒系数、付费模型）
- 机器学习基础认知（推荐系统、用户流失预测的逻辑）

## 二、能力分级与自我评估

| 等级 | 描述 | 典型表现 |
|------|------|----------|
| **L1 入门** | 能看懂现成报表 | 知道 DAU、留存是什么，但不会主动拆解问题 |
| **L2 合格** | 能独立分析常见问题 | 能做漏斗、留存、简单分群，能提出数据驱动的优化建议 |
| **L3 进阶** | 能设计实验并验证假设 | 熟练使用 A/B 测试，会用 SQL 取数，能独立完成完整分析闭环 |
| **L4 专家** | 能建立体系并影响决策 | 能定义产品数据体系，用数据推动战略级决策，指导他人 |

**建议目标**：多数产品经理至少达到 **L2-L3**。

---

## 三、推荐学习路径（高效版）

### 第一阶段：打基础（2-4 周）
1. 搞懂核心指标含义与业务逻辑
2. 熟练使用公司数据平台（神策 / GrowingIO / Amplitude / 火山引擎等）
3. 掌握 Excel 透视表与基础分析
4. 练习：每天花 30 分钟解读自己产品的核心数据

### 第二阶段：实战分析（1-2 个月）
1. 系统学习漏斗、留存、分群、Cohort
2. 学习 A/B 测试完整流程
3. 开始写简单 SQL
4. 练习：每个需求上线后主动做数据复盘

### 第三阶段：体系化（持续）
1. 建立自己的指标库与分析模板
2. 深入业务，培养“数据直觉”
3. 学习如何用数据讲故事、推动决策

## 四、学习资源推荐

### 1. 书籍（强烈推荐）

| 书名 | 适合阶段 | 推荐理由 |
|------|----------|----------|
| 《精益数据分析》 | 入门-进阶 | 经典中的经典，讲透指标与阶段 |
| 《增长黑客》 | 进阶 | 数据驱动增长的实战思维 |
| 《数据化运营》 | 进阶 | 国内实战感强 |
| 《深入浅出统计分析》 | 想补统计基础 | 通俗易懂 |
| 《SQL 必知必会》 | 学 SQL | 薄、实用、上手快 |

### 2. 在线课程 / 专栏

- **极客时间**：
  - 《数据分析实战 45 讲》
  - 《SQL 必知必会》
  - 《A/B 测试从 0 到 1》
- **人人都是产品经理 / 起点课堂**：搜索“产品经理数据分析”
- **慕课网 / 网易云课堂**：Excel + SQL 基础课
- **Coursera / Udacity**：Google Data Analytics 证书（英文，体系完整）

### 3. 实战工具学习

| 工具类型 | 推荐工具 | 学习建议 |
|----------|----------|----------|
| 数据分析平台 | 神策、GrowingIO、Amplitude、Mixpanel、火山引擎 | 以公司实际使用的工具为主，官方文档 + 实操 |
| 表格 | Excel / Google Sheets / 飞书多维表格 | 重点练透视表和数据清洗 |
| SQL | 本地用 SQLite 或在线 SQL 练习平台 | 刷题网站：LeetCode Database、牛客、SQLZoo |
| 可视化 | Tableau Public、Power BI、飞书图表 | 先学会选对图表，再追求高级功能 |

### 4. 优质公众号 / 博客 / 社区

- 人人都是产品经理（数据分析相关文章）
- 数据产品经理相关专栏
- 知乎「产品经理」「数据分析」话题高质量回答
- GrowthHackers、Reforge（英文进阶）
- 公司内部数据同学的分享（最有价值）

### 5. 练习方式（比看课更重要）

1. **每日数据复盘**：每天花 15-20 分钟看核心指标，记录异常与假设
2. **需求复盘模板**：每个功能上线后强制做数据复盘
3. **模拟分析题**：找公开数据集（Kaggle）或自己产品数据做完整分析报告
4. **教别人**：给团队讲一次数据分析方法，是最好的巩固方式

## 五、实用分析模板（可直接套用）

### 1. 问题分析通用框架
1. 问题是什么？（明确业务问题）
2. 相关指标有哪些？如何拆解？
3. 数据表现如何？（对比时间、分群、渠道）
4. 可能原因有哪些？（产品、技术、运营、外部）
5. 验证方法是什么？（实验 / 进一步分析）
6. 结论与行动建议

### 2. 功能上线复盘模板
- 上线目标与成功标准
- 核心数据表现（对比上线前后）
- 分群数据表现
- 意外发现
- 结论与下一步行动

---

## 六、最后的建议

1. **先用起来，再追求完美**。数据分析能力是练出来的，不是学出来的。
2. **业务理解 > 技术深度**。产品经理的优势是懂业务，数据只是工具。
3. **建立自己的指标库和分析模板**，用多了就会形成肌肉记忆。
4. **多和数据同学、研发同学聊天**，很多坑和经验只能靠交流获得。

---

**一句话总结**：  
会看数据是基础，会拆解问题是关键，会验证假设并推动决策才是产品经理数据分析的终极目标。

祝你早日从“数据小白”变成“数据驱动型产品经理”！
